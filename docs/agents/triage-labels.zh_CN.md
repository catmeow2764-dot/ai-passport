# Triage Labels

Skills 使用五个 canonical triage roles。这个文件把这些 roles 映射到此 repo issue tracker 中实际使用的 label 字符串。

| Label in mattpocock/skills | Label in our tracker | 含义                                   |
| -------------------------- | -------------------- | -------------------------------------- |
| `needs-triage`             | `needs-triage`       | 维护者需评估此 issue                    |
| `needs-info`               | `needs-info`         | 等待提交者补充信息                      |
| `ready-for-agent`          | `ready-for-agent`    | 已充分规约，可交 AFK agent              |
| `ready-for-human`          | `ready-for-human`    | 需人工实现                              |
| `wontfix`                  | `wontfix`            | 不会处理                               |

当某个 skill 提到 role（例如 "apply the AFK-ready triage label"）时，使用此表中对应的 label 字符串。

编辑右侧列，使其匹配你实际使用的 vocabulary。
